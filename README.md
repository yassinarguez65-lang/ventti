# Ventti-korttipeli

Ventti on JavaScriptillä toteutettu korttipeli, jossa pelaaja pelaa tietokonetta vastaan.

## Ominaisuudet

- Korttien jakaminen pelaajalle ja jakajalle
- Korttien nostaminen
- Pelin voittajan määrittäminen
- Uuden pelin aloittaminen

## Toteutus

Projekti on toteutettu HTML:llä, CSS:llä ja JavaScriptillä. JavaScriptissä käytetään luokkia ja olioita pelin toimintojen hallintaan.

Projekti on toteutettu osana tieto- ja viestintätekniikan opintoja.
